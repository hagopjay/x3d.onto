# Glossary (as the sources use the terms)

- **Grades C / L / S** — Confirmed (opened/ran it), Likely (reading or reputable summary), Suspected (unchecked; a model's paraphrase of a page is S). Shroud ledger uses a different set: Confirmed / Likely / Contested / Suspected / Question (see EVIDENCE.md). [DOC, EVIDENCE]
- **X3D Ontology** — OWL/Turtle encoding of X3D (4.0 standard, 4.1 draft dated 29 Sep 2026), generated from X3DUOM by X3duomToX3dOntology.xslt (Ant build.xml, 111 targets); "for querying and reasoning", not rendering. Names are ID labels only. [DOC §1]
- **X3DUOM** — X3D Unified Object Model: machine-readable list of all nodes and fields ("single source of truth", 267 concrete nodes); XSD, x3d.py and the ontology derive from it. [DOC, FW]
- **XSD / Schematron** — XSD checks structure (cannot see a dangling USE); Schematron = Consortium's rule-based checks, not run here (needs Java/X3DJSAIL). [DOC App D]
- **Turtle / RDF / OWL** — graph serialisation / data model / ontology language (description-logic based, open-world). [H21, DOC]
- **Open vs closed world** — open: missing statement = unknown (OWL, so it cannot gate); closed: not allowed = forbidden (validation). SPARQL `FILTER NOT EXISTS` is the closed-world escape hatch. [DOC]
- **SPARQL** — RDF query language; x3d_mcp exposes it via `query_ontology`. [REF]
- **SHACL / ShEx** — shape languages to validate graph data against constraints (closed-world). Not shipped by anyone; DOC §6 row 8 is the planned layer; chapters unread. [DOC, fetch-list]
- **hasChild / hasChildren / hasParent** — containment property lattice; per-field sub-properties carry rdfs:domain/range. Over-predicts because ranges are abstract types. [27 #3]
- **DEF / USE** — node naming / reuse. Rules: DEF exists, same node type, defined first. Turtle form: USE individual `:<DEF>-USE-<n>` typed with node class, `owl:sameAs :<DEF>`. [28]
- **Dangling USE / wrong-type USE / USE-before-DEF** — the three USE faults; SPARQL sees the first two, not the third (no document order). [28]
- **Ladder (rungs 0-7)** — Parses, Typed, Valid, Coherent, Lawful (ontology + Schematron/SHACL), Visible, Complete, Meaningful. 0-3 exact; 6-7 judgment + record. [DOC]
- **Valid / visible / complete** — three tests: XSD-valid, draws something (frame check), shows what was asked (judge). [DOC §2]
- **Frame check** — fork PR #5: blank under 0.05%, sparse under 1% non-background pixels. [DOC]
- **sc: ontology** — spatial-cognition ontology in Polys's 3D_perspective_skill (w3id.org/spatial-cognition#), loaded as separate extension graph. [DOC]
- **Geons** — Biederman's simple volumes for object recognition; Polys 2024 asks "Does the theory of Geons apply to LLMs?" [P24]
- **Polys 2024 strategies** — zero-shot, chain of thought, system prompt, few-shot (5 examples). Prompts 0-4 coloured primitives with spatial prepositions; 5-8 named objects; 9 water pump. [P24]
- **DSPy arms** — (a) plain prompt, (b) DSPy "Full allowed" (B_prog.json, picked profile Full), (c) DSPy "Full barred" (results_nofull/B_prog.json, Goodhart-resistant rerun), (d) few-shot with hand-written examples. DSPy thread = INDEX thread 68 (optimiser; prompts "copied verbatim from research/dspy-2026-10-17"). [30]
- **Goodhart pattern** — when the check is the target the model satisfies the check: Full-allowed DSPy prompt makes every valid scene declare profile Full (67/67) and still emits forbidden roughness (18 scenes); repair likewise deletes what it cannot fix (completeness 71.8→61.8→38.5%). [30, DOC §3]
- **Parts-and-contact check** — parts_contact.py: Transform-composed world boxes for Box/Sphere/Cone/Cylinder/point lists; contact tolerance 5%; strict (resting contact) vs loose. [30]
- **Judge / judge bench v2 / Y8 / E1 / Y9 / spine** — model judges of contact sheets; Y8 completeness pass; E1 report-driven repair + retrieval (300 prompts, 7 models); Y9 SFT/DPO of 8B; spine = 3,058-scene corpus (BigQuery). Sources not ingested. [DOC]
- **x3dprov / tether** — hash-chain provenance record in head meta/Metadata nodes that survives Blender round trip; edit after last step → `stale`, deleted step → `broken-chain`. [DOC, FW]
- **Flywheel** — spec → agent → validating x3d_mcp → Blender (+fork) → runtime X_ITE → verdict → back to agent, with x3dprov tether. [FW; INDEX drift row]
- **OntoGuard** — name of two unrelated things, both S (ACL 2026 Findings graph checker; Towards AI ontology firewall). [DOC §8]
- **Rule of three** — zero events in n trials → 95% upper bound ≈ 3/n. [DOC App D]
