# Gobbler discoveries — portable Loom candidates

This addition-only kit is a proposal for the global Loom, not an automatically promoted rule set. It contains no scene, music, imagery or private Giza assets. Apply the accompanying patch at a repository root, inspect the controls, then register rules using that repository's actual conventions. No upstream registration or push is implied.

## Run the controls

Python dependencies for the numerical bake controls: numpy and Pillow. The remaining Python predicates use the standard library. Node controls require no npm dependencies.

```sh
python3 loom-feedback/gobbler-cabinet/tests/predicates.py
python3 loom-feedback/gobbler-cabinet/tests/radiance.py
node loom-feedback/gobbler-cabinet/tests/stream.cjs
node loom-feedback/gobbler-cabinet/tests/profiler.cjs
```

## Contract subtleties

A ready resource is not an observed camera arrival. A visibility toggle is not an unload, and an unload request is not a VRAM measurement. A source hash is not a standards-validation certificate. A schema-valid shader can contain undefined expressions. A black or missing picture is a diagnostic flag, not a complete explanation. A successful two-minute run does not measure a ten-hour leak. Every gate should name both the failure it catches and the counterexample it permits.

The pure controllers deliberately inject a clock and a load adapter. Their tests use synthetic clocks and GL queries; those are instrument controls, not hardware measurements. `tools/gates.py` is a narrow semantic pass, not a full validator. Its degenerate-topology check detects repeated indices, not every geometrically collinear triangle. Literal smoothstep checks do not prove dynamic edge ordering. The tangent fixture establishes a declared path, not the physical correctness of arbitrary bases.

Preserve a minimal failure, an accepted counterexample, a candidate hash, a pinned instrument, actual observations, limits and a promotion decision. This is the foldback unit: a reproducible distinction rather than a memorable anecdote.
